Brand Overview
Qatar Living is a localized community platform with the tagline "One Place, Endless Choices." The brand identity emphasizes trust, community, and local connection across Middle Eastern markets (Qatar, Arabian, Oman).
Logo System
Main Logo Structure
Primary Logo: Country name (Qatar/Arabian/Oman) positioned above "LIVING"
Wordmark: "LIVING" with distinctive styling where "IN" is highlighted in orange, rest in dark blue
Unique Element: The "IN" letters feature a curved connecting line that extends beyond typical structure
Tagline: "One Place, Endless Choices" (use strategically, see usage guidelines below)
Logo Usage Rules
Use FULL logo with tagline for:
Corporate stationery (letterheads, business cards)
Website headers & footers
Brand advertisements and billboards
Presentation templates (cover/closing slides)
Email signatures
Large merchandise (t-shirts, mugs)
Signage and brand introductions
Use logo WITHOUT tagline for:
Internal documents & reports
Space-constrained digital ads
Video opening/closing frames
Small promotional items (pens, USBs)
When brand recognition is already strong
Logo Specifications
Minimum Size: Print = 2cm width | Digital = 130px width
Safe Space: Measure using the height of letter "N" as unit "x", maintain minimum "x" spacing on all sides
Spacing Grid: Logo built on proportional grid system visible in guidelines
Logo Variations
Country versions: Qatar, Arabian, Oman (each with/without tagline)
Color variations: Full color, white on dark, dark on light, monochrome (black/white)
Subsection lockups: Properties, Classifieds, Vehicles, Jobs, Services, Rewards (with department names in orange below "LIVING")
Brandmark/Icon
Standalone "IN" symbol can be used for: app icons, social media profiles, favicons, watermarks, small-scale branding
Available in: filled versions (blue background, orange background), outline versions (blue stroke, orange stroke)
Icon-only usage: when space is extremely limited or brand has strong recognition

Typography
Primary Typeface: Prelude
Prelude Bold: Headings, display text
Display Headline: Size 75pt
H1: Size 60pt
Always use +100 tracking (letter spacing)
Leading: Type size + 12pt (e.g., 24pt leading on 12pt type)
Prelude Regular: Body text
Subheader: Size 30pt
Body: Size 24-30pt
Secondary Typeface: Public Sans
Public Sans Bold: Alternative headings
Display Headline: Size 75pt, Black weight
H1: Size 60pt, Bold weight
Public Sans Regular: Alternative body text
Subheader: Size 35pt
Body: Size 30pt
Tracking: 0 to +50
Leading: Type size + 2pt (e.g., 14pt leading on 12pt type)
Arabic Typeface: GE SS TWO
GE SS TWO Bold: Arabic headings
GE SS TWO Medium: Arabic subheadings
GE SS TWO Light: Arabic body text
Size hierarchy: 75pt (main), 60pt (H1), 30pt (subhead), 24pt (body)
Typography Guidelines
Uppercase for emphasis in Prelude
Sentence case for body text in both typefaces
Prelude requires more generous letter spacing (+100 tracking)
Public Sans for clarity when legibility is paramount
Avoid excessive formatting (minimal bold, headers, bullets unless requested or essential)
Graphic Elements
Pattern System
Created from "IN" brandmark through rotation and repetition
Can be used as backgrounds in blue, orange, or outline versions
Pattern maintains brand identity while adding visual texture
Brandmark Cropping
Brandmark can be cropped for design flexibility
Divide height by 6 sections
Can crop after 4th or 5th vertical section
Creates dynamic layout options: upper left, upper right, lower corners, full width applications

Don'ts (Critical Rules)
Logo Don'ts
❌ Don't stretch or distort the logo
❌ Don't rotate or tilt the logo
❌ Don't change the country name position
❌ Don't make logo transparent or reduce opacity
❌ Don't add strokes/outlines to logo
❌ Don't place logo on busy background images without proper contrast
❌ Don't separate the "IN" color from the rest of the wordmark
Color Don'ts
❌ Don't use colors outside the defined palette
❌ Don't use dark blue and orange in equal proportions (follow 50/30/20 rule)
❌ Don't use low-contrast color combinations that reduce legibility
Typography Don'ts
❌ Don't substitute typefaces with similar alternatives
❌ Don't use Prelude without proper tracking (+100)
❌ Don't mix too many type weights in single design
❌ Don't use excessive decorative typography

When designing for Qatar Living, prioritize:
✅ Clean, professional layouts with hierarchy
✅ Consistent use of dark blue and orange (50/30 ratio)
✅ Generous white space and breathing room
✅ Appropriate logo version for context (with/without tagline)
✅ Prelude for distinctive brand voice, Public Sans for clarity
✅ Pattern elements for visual interest without overwhelming
✅ Mobile-first, responsive approach for digital
✅ Localization (correct country name for market)
